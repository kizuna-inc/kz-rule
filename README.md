# Kizuna AI Tools - Rules Collection

A collection of rule files for AI agents to follow when working on projects.

## Overview

This repository contains Markdown files that define specific rules, guidelines, and best practices for AI agents (like Claude Code) to follow when performing tasks such as coding, debugging, or project setup.

Each rule file in the `rules/` directory provides actionable instructions that AI agents can reference to ensure consistency and quality in their work.

## Usage

When working on a project, AI agents can refer to the relevant rule files in this repository to:

- Follow specific technology preferences (e.g., using Bun instead of Node.js)
- Adhere to coding standards and patterns
- Apply consistent project setup procedures
- Implement testing and debugging methodologies

## Available Rules

See the `rules/` directory for all available rule files:

- `use-bun.md`: Guidelines for using Bun as a replacement for Node.js/npm/pnpm/vite

## Contributing

To add a new rule:
1. Create a new Markdown file in the `rules/` directory
2. Follow the format used by existing rule files (include frontmatter with description, globs, etc.)
3. Ensure the rule is clear, actionable, and focused on a specific aspect of AI agent behavior
